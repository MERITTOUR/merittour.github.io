1. 시스템 개요

1.1 목적

골프투어 회원권 보유 고객이 회원 우선예약 기간에 원하는 골프장·일정·인원을 직접 예약하는 웹 서비스. 기존에는 전화·카카오톡으로 접수하던 예약을 회원이 직접 진행하고, 사내 예약 시스템(엠클릭)과 상태를 연동한다.

1.2 대상 사용자

구분설명특징
정회원회원권 보유 본인전 차수 우선예약 참여
지정회원회원권에 지정된 동반 회원정회원과 동일 회원권 기준 적용
특별회원특별 회원권3차 우선예약만 참여 (§5)
사용자 특성 — 이용 고객의 상당수가 50~70대이며 모바일 예약 비중이 높다. 글자 크기·터치 영역·단계 수를 시니어 기준으로 설계할 것. (§9.3)

1.2.1 회원 등급별 예약 가능 인원 2027 가이드

FR-1.2 회원 동반 기준 — 회원 우선으로 확보된 예약이 회원 없이 일반 고객만의 투어로 진행되면 1인당 10만 원 업차지가 적용된다. 예약 확인 단계에서 이 조건을 안내한다.

1.3 설계 원칙

  1. 선택은 즉시 반영 — 「적용」 버튼 없이 고르면 바로 적용되고 다음 항목으로 자동 이동.
  2. 스크롤 최소화 — 큰 사진·장식 최소화, 첫 화면에서 검색 시작 가능.
  3. 4가지 질문으로 예약 — 어디서 / 어디로 / 얼마나 / 몇 명.
  4. 회원 기준 자동 제한 — 인원 상한·예약 가능 횟수를 회원권 기준으로 화면에서 강제.

5. 우선예약 차수 운영 핵심

5.1 차수 개방 · 횟수 누적

정해진 시각에 차수가 열리고, 열릴 때마다 예약 가능 횟수가 누적된다. 회원권 종류와 무관하게 동일한 횟수를 배정한다.

차수개방 시각추가 횟수누적 가능참여 대상
1차2026-10-12 (월) 10:00+1회1회정회원·지정회원
2차2026-10-13 (화) 10:00+2회3회정회원·지정회원
3차2026-10-14 (수) 10:00+2회5회정회원·지정회원 + 특별회원
자유예약2026-10-15 (목) 10:00—잔여 객실전 회원
2027 시즌 확정 사항 — 오픈 일시는 2026년 10월 12일(월), 회차는 월~화 1회 · 화~수 2회 · 수~목 2회 = 총 5회(사내 「2027 시즌 골프투어 예약 안내」 기준). 오픈 시각은 아직 확정 예정이며(안내문 기준), 각 차수 시각과 자유예약 개방일은 관리 화면에서 설정한다. 위 표의 10:00은 참고 화면의 시연값이다.
같은 기간에 함께 가는 회원도 각자 로그인해 각자 예약하는 것이 원칙이다(합산 예약 아님).
  • FR-5.1 1차 개방(10/12 10:00) 후 10/13 09:59:59까지는 1회, 10/13 10:00에 3회, 10/14 10:00에 5회가 된다(초 단위 정확도 필요).
  • FR-5.2 특별회원은 3차만 참여 → 3차 개방 시 2회. 1·2차는 화면에 「해당 없음」으로 표시.
  • FR-5.3 개방 시각·횟수·자유예약 개방일은 운영자가 관리 화면에서 변경할 수 있어야 한다(연도마다 달라짐).
  • FR-5.4 개방 전에는 「1차 우선예약 10/12(월) 10:00 오픈 · +1회 추가」처럼 오픈 일정과 추가 횟수를 안내한다.
  • FR-5.5 예약 1건 확정 시 열린 차수 중 잔여가 있는 차수에서 1회 차감한다.

5.2 자유예약 기간 (우선예약 종료 후) 중요

자유예약 개방 시각이 지나면 우선예약 운영이 끝나고 일반 예약 사이트로 전환된다. 차수·횟수 개념이 화면에서 사라지고, 잔여 객실만 보고 예약한다.

항목우선예약 기간자유예약 기간
예약 가능 횟수차수별 배정·누적 (최대 5회)제한 없음 — 횟수 검사·차감 모두 하지 않음
랜딩 상단 안내「예약 가능 N회 · 1차 잔여… · 다음 차수 오픈」「자유예약 기간 — 잔여 객실에 한해 예약」 (차수 표기 없음)
로그인 완료 화면남은 예약 가능 횟수자유예약 안내 (횟수 미표시)
마이페이지차수별 사용/배정·진행바차수 패널 미표시 — 자유예약 안내로 대체
예약 확인·완료「확정 시 1회 사용」·남은 횟수「횟수 제한 없음」·차감 문구 없음
예약 차단횟수 0이면 차단 + 다음 차수 안내차단하지 않음 (잔여 객실만 판정)
  • FR-5.7 자유예약 개방 시각을 지나면 위 항목이 일괄 전환되어야 한다. 시각 판정은 초 단위로 정확해야 하며, 페이지를 새로 열지 않아도(다음 예약 진행 시점에) 반영되는 것이 바람직하다.
  • FR-5.8 자유예약 기간에는 예약 확정 시 차수 횟수를 차감하지 않는다. 우선예약 기간에 사용한 이력은 마이페이지 기록용으로 보존한다.
  • FR-5.9 자유예약 개방 시각도 운영자가 관리 화면에서 설정한다(시즌마다 달라짐). 우선예약을 운영하지 않는 시즌에는 처음부터 자유예약 상태로 둘 수 있어야 한다.
  • FR-5.10 자유예약 기간에도 회원권 예약 가능 인원 상한(FR-6.2)과 자동 취소 사유(FR-1.1)는 그대로 적용된다. 풀리는 것은 예약 횟수 제한뿐이다.

6. 예약 요구사항

6.1 인원 규칙

  • FR-6.1 최소 2명부터 예약 가능 (1명 불가 — 감소 버튼 비활성).
  • FR-6.2 최대 = 회원권 예약 가능 인원. 상한 도달 시 증가 버튼 비활성 + 「최대 N명(회원권 기준)」 안내.
  • FR-6.3 객실 수는 2인 1실 기준으로 자동 환산해 표시(예: 4명 → 2실). 4인실(패밀리룸)이 있는 숙소는 룸타입에 따라 환산이 달라지므로 숙소별 정원 데이터를 사용한다.
  • FR-6.4 홀수 인원은 화면에서 받되, 싱글 차지 등 추가 요금은 사후 수기 정리(자동 계산하지 않음).

6.3 금액 표시 · 요금 정책

  • FR-6.8 상품 상세·예약 단계에서는 금액을 표기하지 않는다(현재 참고 화면과 동일). 일정마다 투어비가 달라지고 항공 발권 전이라, 화면에는 선택한 일정·인원·객실 수만 요약하고 「요금은 예약 확정 후 담당자가 안내」로 표기한다. 향후 금액 표기 단계로 확장할 경우 1인당·총액을 함께 노출한다.
  • FR-6.9 기본 포함 내역은 왕복 항공권 · 공항–리조트 송영 · 여행자보험 · 숙박 · 식사 · 라운딩이다(All-Inclusive). 상품별 추가 요금(2색·3색 골프 투어비, 싱글룸, 2인 플레이, 일본 공휴일 체재비 등)은 별도 안내한다.
  • FR-6.10 단가·환율은 사내 마스터 값을 사용한다(숙소별 체재비, 왕복 송영비, 월별 환율).
  • FR-6.11 환율 기준 — 지상비·현지 비용은 출발월 기준 특정일의 하나은행 「현찰 살 때」 최초 회차 환율로 원화 산정한다. 계약 시 안내된 원화 금액이 기준이며 이후 환율 변동에 따른 재정산은 없다.
    • 2026 시즌까지 — 출발월의 두 달 전 1일 기준
    • 2027 시즌부터 — 출발월의 세 달 전 1일 기준 (예: 6월 출발 → 3월 1일)
    기준 개월 수가 시즌마다 바뀌므로 운영자가 관리 화면에서 설정할 수 있어야 하며, 이미 확정된 예약에는 예약 시점의 기준이 그대로 적용되어야 한다.
  • FR-6.12 체재비·송영비 등 현지 비용은 원화 사전 입금만 가능(현지 개별 지불 불가). 항공요금은 발권 시점 실제 운임 기준으로 확정된다.

7. 예약 대기 신규

마감된 일정도 회원이 대기를 걸 수 있게 한다. 사내 예약 구분값의 「대기」를 활용한다.

  • FR-7.1 달력에서 마감 날짜도 클릭 가능. 선택 시 CTA가 「예약 대기 신청」으로 전환된다.
  • FR-7.2 신청 화면에 숙소·출발일·기간·인원과 안내(대기 순서대로 연락, 대기 중 요금 미청구, 회원 정보의 연락처로 안내)를 표시한다.
  • FR-7.3 접수 시 예약 상태 「대기」로 등록하고, 대기 순번을 관리한다.
  • FR-7.4 취소분 발생 시 대기 순서대로 담당자가 연락·전환할 수 있어야 한다(자동 확정 여부는 운영 정책에 따라 결정).
  • FR-7.5 대기 신청은 예약 가능 횟수를 차감하지 않는다(확정 전환 시 차감).
